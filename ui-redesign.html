界面优化参考稿

智能快递分类系统 · 界面美化方案

基于现有 PyQt5 功能不变的六个界面重绘。配色改为中性浅底 + 卡片，字体由楷体换成系统黑体，操作层级由"三个等大按钮纵排"改为"主次分明的工具栏"，表格与弹窗全部自定义样式。所有界面都按现有功能绘制，未改动业务逻辑。

字体 楷体 → 微软雅黑 布局 顶部标签页 → 左侧导航 背景 全屏渐变蓝 → 浅灰底 + 白卡片 按钮 单一样式 → 主 / 次 / 危险三级 表格 Qt 默认 → 自定义表头与行高 反馈 原生弹窗 → 卡片式对话框与轻提示

一、优化方向对照

每条都是可在 Qt 里直接落地的改动，按影响面从大到小排列。

项目现状建议落地方式
字体 楷体 KaiTi，16/14px 微软雅黑 UI，正文 14px / 标题 16px 加粗，数字用等宽 QFont("Microsoft YaHei UI")
整体背景 qlineargradient 深蓝→浅蓝铺满图片区 浅灰底 #F4F6FA，内容放进白色圆角卡片 QSS background + 卡片 QFrame

空状态 空白图片区，无引导 虚线框 + 一句操作提示，告诉用户下一步点哪里 QLabel 占位 + QSS dashed

三、登录 / 注册

现在是一个 350×250 的小表单，楷体标题加两个输入框。建议改为左右分栏、放大到 860×540——登录页是答辩演示的第一屏，值得多花点功夫。

  • 左右分栏左侧深色品牌区放系统名称、一句话定位与版本号；右侧只保留必要的输入框。
  • 标签置于输入框上方焦点态为主色描边加 3px 浅蓝光圈，一眼能看出光标在哪。
  • 注册态复用同一窗口追加"确认密码"一行，主按钮文字由"登录"变"注册"，其余不动。
  • 错误就近提示用户名或密码错误显示在输入框下方，不再弹窗打断输入。

四、主界面 · 图片检测

功能区由"标题 + 两张图 + 两个整行按钮 + 一个文本框"改为"工具栏 + 双卡片工作区 + 结构化信息卡"。这是改动最大、收益也最明显的一屏。

  • 导航移到左侧当前项实心高亮，底部固定显示当前登录用户与角色，退出登录放在这里。
  • 操作进工具栏上传图片（次要，白底描边）与开始检测（主要，实心蓝）并排放在右上，不再各占一整行。
  • 识别信息结构化包裹类型、收件人、电话、运单号、地址逐行展示；原始 OCR 文本折叠在右侧虚线框内备查。
  • 结果图标注检测框包裹框用绿色、面单框用蓝色，框上直接标类别与置信度，而不是只给一张图。

五、主界面 · 视频检测

六、历史记录

表格目前是 Qt 默认外观：竖向网格线、行高压得紧、类型与操作全靠文字区分。建议改为自定义表头加状态标签，并在顶部补一个搜索与筛选栏。

  • 去竖线、加行高只保留行间细横线，行高 34px，长地址自动截断并保留完整内容提示。
  • 状态用标签表达包裹类型用琥珀色标签，识别类型用中性标签，扫一眼就能分类。
  • 行内操作按钮"详情"为描边小按钮，"删除"为红色描边小按钮，不再与内容抢视觉。
  • 详情改侧栏抽屉现在是弹出文本框；建议改为右侧抽屉卡片，字段分行显示，可对照原图。

八、登录日志（管理员）

登录日志是安全审计的入口，现在四个纯文字列里"成功 / 失败"几乎看不出差别。建议用色标签强化结果，并补上筛选。

  • 结果色标签成功为绿色、失败为红色，异常登录一眼可见。
  • 筛选标签全部 / 成功 / 失败三个筛选 建议新增，排查异常时不必逐行找。
  • 保留失败记录失败登录同样入库，用户名快照保留，便于定位异常尝试。
  • 时间统一格式用等宽字体并统一到分钟，列宽稳定不跳动。

十、实施顺序与起始样式表

建议按下面的顺序改，每一步都能单独运行验证。前三步不改任何业务逻辑，风险最低、观感提升最快。

步骤内容涉及文件工作量
1 · 打底全局字体换为微软雅黑，页面底色、卡片、按钮、输入框、表格的 QSS 统一window.py 新增 QSS 常量约 60 行样式，半天
2 · 组件按钮分主 / 次 / 危险三级；表格去竖线、加行高、状态改用色标签window.py 各 initUI半天
3 · 反馈登录页改左右分栏；QMessageBox 按钮改中文或替换为自定义对话框；成功提示改轻提示LoginDialog / EditUserDialog半天到一天
4 · 结构顶部标签页换左侧导航（QListWidget + QStackedWidget），功能与信号槽全部保持MainWindow 基类与 initUI一天
5 · 加分识别信息结构化字段、历史详情抽屉、用户管理概览数字与新增用户window.py / db.py视时间取舍
